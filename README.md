This is a script for culling photos with a PS4 controller through a GUI

Control functionality includes:
- Next/previous photos
- Move photo to/from the "delete" folder
- Jump zoom in/out
- Zoom in/out
- Pan by joystick control
- Toggle keeping the zoom ratio
- Toggle keeping the pan location
